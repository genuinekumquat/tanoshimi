| NFR-10 | 에러 응답 | `/api/**`는 `ApiResponse` + `ErrorCode`(HTTP status + 한국어 메시지) 일관 포맷. 뷰는 `error/403` 등 |
| NFR-11 | 스키마 관리 | `schema.sql` 단일 원본 + 번호 마이그레이션. JPA `ddl-auto: update`는 보조 |
| NFR-12 | 접근성/반응형 | 모바일 우선 반응형. 시맨틱 마크업 |
