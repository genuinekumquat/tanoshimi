## 2. 파티 찾기 → 참여 신청 — 1분 · 화면 A

## 리허설 후 초기화 SQL

신청·수락·확정은 한 번만 할 수 있어서, 리허설을 같은 파티로 했다면 본 시연 전에 되돌린다. (`mysql -u scit -p tanoshimi` 에서 실행)

```sql
SET @party = (SELECT id FROM parties WHERE title = '도쿄 시부야·하라주쿠 카페 투어');
SET @yuja  = (SELECT id FROM users WHERE email = 'yuja@test.com');
SET @sched = (SELECT id FROM trip_schedules WHERE party_id = @party);

-- 유자차 신청·파티원·채팅방 멤버 지우기
DELETE FROM party_applications WHERE party_id = @party AND applicant_id = @yuja;
DELETE FROM party_members      WHERE party_id = @party AND user_id = @yuja;
DELETE crm FROM chat_room_members crm
  JOIN chat_rooms r ON r.id = crm.room_id
 WHERE r.type = 'party' AND r.party_id = @party AND crm.user_id = @yuja;

-- 계획표를 확정 전으로, 편집권은 처음처럼 방장(ハルカ)에게, 투표 지우기
UPDATE trip_schedules
   SET status = 'draft', submitted_at = NULL, confirmed_at = NULL,
       locked_by_user_id = (SELECT owner_user_id FROM parties WHERE id = @party)
 WHERE id = @sched;
DELETE FROM trip_schedule_votes WHERE schedule_id = @sched;
```

- 리허설 때 만든 일정 블록·채팅 메시지는 남는다. 깨끗하게 하고 싶으면 계획표의 **전체 비우기**를 누른다.
